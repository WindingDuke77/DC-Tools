# DC Tools

Unofficial community tools for [Data Center](https://store.steampowered.com/app/4170200/Data_Center) by [Waseku](https://waseku.com).

## Tools

- **Color Palette Generator** — Pick a server type or create a custom palette. Rack and cable colours derive automatically from the server colour. Includes presets for System, Mainframe, RISC, and GPU server types, localStorage saving, and shareable URLs.

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- React Router (HashRouter for GitHub Pages compatibility)

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via the included GitHub Actions workflow.

To deploy manually:

```bash
npm run deploy
```
